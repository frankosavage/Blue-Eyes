# Blue-Eyes

**Blue-Eyes** es una landing page desarrollada para un emprendimiento de **gráfica e imprenta personalizada**.

El objetivo principal de la página es funcionar como un **canal de captación de clientes**, mostrando los productos y servicios disponibles y llevando al usuario a realizar una consulta o pedido directamente por **WhatsApp**.

La página está diseñada para que el usuario pueda conocer rápidamente lo que ofrecemos, entender cómo realizar un pedido y tener un acceso directo al contacto.

## 📌 Secciones

### 🛍️ Productos

Sección destinada a mostrar los diferentes productos que podemos realizar y personalizar.

Permite que el visitante conozca rápidamente las opciones disponibles antes de realizar una consulta.

### 📋 Tres pasos sin vueltas

Sección que explica de forma sencilla el proceso para realizar un pedido.

El objetivo es que el cliente pueda entender **cómo comprar en pocos pasos**, sin información innecesaria ni procesos complicados.

### 📸 Instagram

Sección destinada a mostrar nuestras últimas publicaciones de Instagram.

De esta manera, los visitantes pueden conocer trabajos recientes y tener una referencia visual de los productos y trabajos realizados.

### 💬 Llamado a la acción

Sección final enfocada en convertir la visita en una consulta.

Cuenta con un botón directo a **WhatsApp** que abre una conversación con un **mensaje preconfigurado**, facilitando el primer contacto entre el cliente y el emprendimiento.

## 🎯 Objetivo

La página fue pensada principalmente como una **landing orientada a conversión**.

El recorrido busca llevar al usuario desde:

```text
Conocer el emprendimiento
        ↓
Ver productos y trabajos
        ↓
Entender cómo realizar un pedido
        ↓
Ver publicaciones recientes
        ↓
Consultar por WhatsApp
```

De esta manera, la página funciona como un pequeño **embudo de ventas**, utilizando WhatsApp como principal canal de contacto.
